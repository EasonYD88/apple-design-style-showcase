# Apple Design Style Demo

A static sample site that demonstrates the `apple-design-style` skill. No dependencies are required.

## Open Directly

Open this file in Finder:

```text
/Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-demo/index.html
```

Or run this in Terminal:

```bash
open /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-demo/index.html
```

## Open with a Local Server

To serve the demo over a local HTTP address, run:

```bash
cd /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-demo
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open this URL in a browser:

```text
http://127.0.0.1:4173/
```

Press `Control + C` in Terminal to stop the server.
