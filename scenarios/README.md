# Apple Design Style Scenario Gallery

This folder contains three static sample sites that demonstrate the visual effect of the `apple-design-style` skill:

- `health.html`: Health tracking
- `schedule.html`: Schedule management
- `files.html`: File manager

## Open

Open the gallery page directly:

```bash
open /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-scenarios/index.html
```

Or open each scenario directly:

```bash
open /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-scenarios/health.html
open /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-scenarios/schedule.html
open /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-scenarios/files.html
```

To serve the examples over local HTTP:

```bash
cd /Users/daiyizhe/Documents/GitHub/projects/outputs/apple-design-style-scenarios
python3 -m http.server 4174 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:4174/
```

Press `Control + C` to stop the server.
